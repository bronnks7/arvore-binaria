# Árvore Binária de Busca

Programa em C para manipular uma árvore binária de busca (ABB). Permite incluir e remover valores sem duplicatas e exibir os percursos em pré-ordem, em ordem e pós-ordem.

## Compilar e executar

Com GCC instalado:

```sh
gcc -Wall -Wextra -o arvore_binaria arvore_binaria.c
./arvore_binaria
```

No Windows, execute `arvore_binaria.exe` após a compilação.

Digite `0` no menu para encerrar.
